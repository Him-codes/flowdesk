# FlowDesk — Business Management Dashboard

FlowDesk is a modern business management dashboard built with React and TypeScript. It brings essential business operations into one interface, with a focus on usability, responsive design, and a clean dashboard experience.

## Live Demo

**[View FlowDesk Live](https://flowdesk-mu-jet.vercel.app/dashboard)**

## Features

- **Dashboard:** View key business metrics, including revenue, customers, transactions, and conversion rate.
- **Customer Management:** View and manage customer records with form validation.
- **Transaction Management:** Browse and manage transaction records.
- **Task Management:** Organize tasks and update their status.
- **Notifications:** View notifications and manage their read status.
- **Analytics:** Access the analytics section.
- **Settings:** Access application settings.
- **Dark and Light Themes:** Switch between visual themes.
- **Responsive Design:** Layouts designed for desktop, tablet, and mobile screens.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Him-codes/flowdesk.git
   ```

2. Enter the project directory:

   ```bash
   cd flowdesk
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

### Production Build

Run the following command to create a production build:

```bash
npm run build
```

## Project Structure

The project is organized into reusable UI components, feature-specific modules, shared styles, and application routes.

- `src/components/` — Reusable interface components.
- `src/features/` — Feature-specific components and functionality.
- `src/styles/` — Global styling.
- `src/` — Application source code.
